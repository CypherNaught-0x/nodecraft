## 2026-10-21 · Meshy is six fixed-price models, with every input inline (#23)

- **One catalog model per Meshy task and price**: text, image and multi-image to 3D, retexture
  from a prompt, retexture from a style image, and remesh. Retexture is two models because the
  card picks a mode by what is wired, and a prompt typed on the card is not a wire; both send the
  same task. Each model fixes the settings that change Meshy's credits (the untextured preview for
  text, textured PBR at 2K for images, 2K for retexture), so the estimate covers what is sent.
- **Prices are estimated at the Pro plan's 0.02 USD a credit.** Meshy bills credits, whose dollar
  price depends on the plan; one dated rate keeps estimates comparable with other providers.
- **Inputs travel as data URIs in the task request**, never through a separate upload, so there
  is one paid request and nothing to clean up. Images are capped at 15 MiB and models at 64 MiB
  before encoding, under Meshy's 20 MB and 100 MB caps after base64 grows them by a third.
- **A wired 3D model must already be a GLB.** The Generate 3D card takes it on a mesh port like
  any media role; the adapter refuses other formats with a message rather than converting them.
- **Cancelling is unsupported**, as for Tripo. Meshy's `DELETE` erases a task and its models, and
  its docs promise neither a refund for a waiting task nor a refusal for a running one, so a
  cancel could throw away a model that was already billed.
- **Result links go through the shared `model_file` checks** (public `https` host, whole GLB) that
  the Tripo adapter now uses too.
