## 2026-10-27 · Rodin V2.5 through the existing fal queue (#41)

Use fal's current Hyper3D Rodin V2.5 standard and fast text/image aliases, with the existing
fal key, async task lifecycle, saved handles and no-replay policy. No Hyper3D credential,
SDK or renderer is added. The [dated contracts and rates](../providers.md#rodin-through-fal)
describe the supported subset; these are live service aliases, not immutable weights.

Bind requests to each published default tier: Gen-2.5-High with PBR material for standard
calls, Gen-2.5-Extreme-Low with Shaded material for fast calls. Both use Auto mesh and GLB.
Standard costs $0.40 and fast $0.10 per call. Do not offer HighPack (another $0.80 on standard),
custom tiers, topology, advanced textures or bounding-box controls without explicit pricing
and compatible decoder bounds. Safety remains on. Only fixed optional seeds and image-mode
alpha preservation are caller-controlled; other advanced switches remain false.

Text mode requires a prompt of at most 1024 characters. Image mode takes one to five ordered
references and an optional prompt; an absent prompt lets the service describe the images.
Keep the host's actual PNG/JPEG/WebP, 1-MiB and 1024-pixel bounds. Only Rodin image requests
receive an 8-MiB encoded allowance, so five legal references can fit. Count escaped JSON plus
all base64 extents before codecs or owned encodings.

Use the owner/app queue root `fal-ai/hyper3d`, as the current queue contract requires, rather
than the full model alias in generated endpoint-path examples. Download only `model_mesh`;
additional meshes, textures and preview URLs confer no routing authority. Its generic
application/octet-stream header is treated as undeclared MIME for Rodin only, then the actual
bytes must pass packed-GLB validation. Standard examples exceed 30 MiB, so all four aliases
admit 256 MiB per file and total, including resumed handles. Legacy model quotas stay fixed.

The existing mesh pipeline retains the original GLB and renders embedded material colours.
External resources remain refused; no sidecar fetch, URL normalization, credential forwarding,
redirect following or paid-create replay is introduced. Native HTTP or an audited transport
is required for execution; WebAssembly compilation alone does not promise builtin browser
networking. Offline fixtures exercise the common host and actual mesh decoder without credit.
