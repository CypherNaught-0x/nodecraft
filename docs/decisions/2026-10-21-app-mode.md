## 2026-10-21 · App mode fills inputs with canvas nodes (#95)

- **A form over one technique node.** App mode opens a full-window form for a selected technique
  node: its published inputs, its exposed parameters, Run and the node's results. `app.form`
  describes it; the UI, MCP and CLI read the same description.
- **Filled inputs are ordinary source nodes.** `app.input_set` places one source node per value
  left of the technique node and wires it in, as one undo step. The form owns a source only while
  it holds a value and is wired to that input alone; wired anywhere else, it is part of the graph and the form
  shows the input as wired. Nothing is hidden from the canvas, so a run, an undo, a save or a
  collaborator sees exactly what the form did. Emptying an input removes its sources, and the
  version's own example feeds it again.
- **Settings are the node's parameters.** Editing one is `node.param_set` on the technique node;
  Reset clears the override.
- **Files are read off the frame, bounded.** On the desktop a chosen file is read on its own
  thread: only regular files, at most one media asset's size, refused before it is read. Text is
  not media and is refused with a message. The browser build can't pick files from the form yet
  and says so.
- **Runs go through the price check.** The form shows what a run costs now (`run.quote`, which is
  read-only) and Run asks for the same quote as the canvas; the form never spends without it.
