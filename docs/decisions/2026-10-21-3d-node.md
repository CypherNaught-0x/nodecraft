## 2026-10-21 · The 3D node: a viewer over wgpu, conversion as an action, colours in the vertices (#111)

- **Models are read and written in `media`.** glTF (embedded buffers and data URIs only), GLB
  and OBJ are read into one triangulated mesh in model space (node transforms applied), with
  positions, normals and linear vertex colours. GLB and OBJ are written. Every count is bounded
  before allocation (`MeshLimits`), and a file that points outside itself (an external URI) is
  refused rather than fetched: a project must not reach the disk or the network because of a
  model it was given.
- **Textures are baked into vertex colours.** A base-colour texture is sampled at each vertex,
  so the preview and both writers carry one colour model. Detail finer than the triangles is
  lost; a textured round trip through NodeCraft is not lossless. Keeping textures is a later
  capability, not a change to this one.
- **Conversion is an action node, not a command.** Commands have no effect that writes assets,
  so "Convert 3D" (`mesh.convert`) is an action: it writes a new model as a result and never
  changes its source, like the image actions.
- **The viewer draws offscreen, then into egui.** `nodecraft-gpu` renders each card's model into
  its own multisampled colour and depth target and copies it into egui's pass through a paint
  callback, so egui's pass needs no depth buffer and a capture (#112) can read the finished
  image. The renderer is installed from eframe's wgpu state by the apps; without it (tests,
  another renderer) the card writes what the model is instead of drawing it.
- **The camera and style are view state.** Turning, zooming (⌘/Alt + scroll) and the
  shaded/unlit/wireframe toggle change nothing in the document, are not undoable and are not
  saved. Model transforms (move, rotate, scale) that would change a capture are document state
  and land as undoable parameters with the capture work, not here.
- **The browser has no decode worker yet.** A model already in memory and at most 8 MiB is
  decoded inline there; larger ones say the preview isn't available.
