## 2026-10-18 · "Turn into" (#60)

- **Dropping a new noodle on empty canvas opens a "Turn into" menu**; dropping a picked-up
  noodle there still disconnects it. The menu lists the kinds the noodle can turn into: those
  whose mode accepts its port type (the planner's predicate, `Registry::compatible`) and that
  have an input for it once created. Sources take no inputs, so they never appear.
- **The node and its connection are one command and one undo step:** `node.create_connected`
  `{canvas, id, kind, pos, from, edge}`. It connects to the new node's first accepting input. The
  caller supplies both new ids, as for `node.create`. Agents can run it too.
- **A router takes the noodle's modality** (its config is set from the dragged port), so a
  router is offered for any noodle. Other kinds start from their defaults.
- **A kind's quick-add key picks it in the menu**; ↑/↓ and ↵ or a click do too, and Escape or a
  click elsewhere closes it. There is no search field: the list is short and letters are
  shortcuts. While the menu is open, canvas keys (undo, delete, quick-add) wait, as they do for
  the palette. Moving the view closes it, since the node goes where the noodle dropped.
